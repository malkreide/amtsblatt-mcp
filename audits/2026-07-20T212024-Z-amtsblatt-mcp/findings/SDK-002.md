## Finding: SDK-002 — Structured tool return types

**Severity:** medium
**Status:** accepted-risk
**Server:** amtsblatt-mcp
**Check-Reference:** SDK-002

### Observed Behavior
Tools return `str` (rendered Markdown), with `response_format='json'` offering a structured alternative.

### Expected Behavior
Pydantic/TypedDict/Dataclass return types for machine-consumable structure.

### Risk Description
Markdown-first returns are less directly machine-parseable. Deliberate: the primary consumer is an LLM reading official-gazette prose, and JSON output is available on request.

### Remediation
Accepted as a design choice. The dual Markdown/JSON envelope already carries `provenance`/attribution; a typed model could back the JSON branch in a later minor.

M

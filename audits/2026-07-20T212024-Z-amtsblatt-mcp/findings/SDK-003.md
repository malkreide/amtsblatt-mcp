## Finding: SDK-003 — Context injection for progress/logging

**Severity:** medium
**Status:** accepted-risk
**Server:** amtsblatt-mcp
**Check-Reference:** SDK-003

### Observed Behavior
Tools do not take `ctx: Context`; per-call latency/status is emitted by the `logged_tool` decorator and structured logger instead.

### Expected Behavior
`ctx: Context` injection for progress reports and MCP-native logging.

### Risk Description
No client-visible progress events. Low impact: each tool is a single fast upstream call, not a long-running job.

### Remediation
Accepted for 0.1.x. Structured JSON logging already covers observability; `ctx` progress can be added if a long-running tool is introduced.

### Effort Estimate
M
